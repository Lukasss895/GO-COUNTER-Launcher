Ako propojiť Patch Notes s GitHubom a C# Launcherom

Ako to funguje bez posielania nového .EXE?

Do svojho GitHub repozitára (napr. `github.com/tvoj-nick/gocounter-web`) vytvoríš súbor `patch_notes.json`. Tvoj C# Launcher pri každom spustení cez webovú požiadavku (HttpClient) stiahne tento súbor a zobrazí nové správy. Nemusíš tak hráčom posielať novú verziu launchera!

1. Vzorový súbor `patch_notes.json` pre tvoj GitHub:

[
  {
    "version": "v1.4.2",
    "date": "27. 10. 2026",
    "title": "Legacy 2016 Sound Pack & Bridge fix",
    "changes": [
      "Pridané autentické 2016 zvuky zbraní",
      "Drops Bridge automaticky beží ako samostatné exe",
      "Optimalizovaný FPS Cap pre 144Hz a 240Hz monitory"
    ]
  }
]

2. C# kód pre sťahovanie Patch Notes z GitHub RAW:

using System.Net.Http;
using System.Threading.Tasks;

public async Task<string> FetchPatchNotesFromGitHub()
{
    string githubRawUrl = "https://raw.githubusercontent.com/TVOJ_NICK/GOCOUNTER/main/patch_notes.json";
    using (HttpClient client = new HttpClient())
    {
        try {
            return await client.GetStringAsync(githubRawUrl);
        } catch {
            return "Chyba pri načítaní Patch Notes.";
        }
    }
}
